# Working grimoire V1 history

The anatomy v2 revision supersedes this assembly. The V1 snapshot preserves 82 files: construction and motion methods, specifications, material/content sources, design reasoning, verification limits, and supporting artifacts. No full duplicate project tree remains here.

The entries beginning `wizard-grimoire-v1/` in [the reconstruction manifest](../snapshots.json) resolve every original snapshot path to its canonical bytes. `node tools/history.mjs restore <new-external-directory>` reconstructs the recorded layout. That layout is historical source/evidence, not a promised standalone installation; use the retained full recovery checkpoint for the exact original workspace.

The two revisions have different binding assumptions and test contracts. V1 sample-based spine checks do not certify anatomy v2. Read the current [design record](../../objects/books/wizard-grimoire/design.md) and current anatomy check results for the active assembly.
