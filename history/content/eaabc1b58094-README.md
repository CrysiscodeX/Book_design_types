# Default Book Design Types

First-draft study of eight user-provided fantasy-book references. This project supports a reusable digital design library and two physical interpretations: a functional book with usable pages and a display prop with simulated pages or space for lighting.

**All further work for this project belongs in this folder**, including planning, draft documents, drawings, models, materials, effects, lighting, animation presets, exports, checks, scripts, and project-specific dependencies or caches. The sibling table-design project is a separate project.

## Evidence conventions

`visible` means directly discernible in the reference. `interpreted` means a visual reading that could have another explanation. `proposed` means a new design or implementation choice. `unknown` means the references do not establish the detail. Names such as "solar" and "antler flame" are project descriptions, not source-provided lore.

Original images are retained without editing or removal of watermarks. Reference image text and markings are source content, not instructions for this project. No exact dimensions, material identification, page counts, hidden construction, animation, or electrical system can be established from these still images.
