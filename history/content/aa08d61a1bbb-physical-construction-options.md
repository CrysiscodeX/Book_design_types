# Physical Construction Options — v0.1

Date: 2026-10-06. All construction systems below are **proposed**. The reference images establish appearance but do not show internal bindings, fasteners, electronics, tolerances, or material identities.

## Functional book with usable pages

The conceptual assembly is a bound page block, front and rear boards, flexible joints, covering/lining, and separately attached decoration. The chosen binding must accommodate the selected page format and opening behavior; neither is specified yet.

| Assembly | Proposed options | Decisions before construction |
|---|---|---|
| Pages and binding | Real sheets with a binding suitable for the intended use | Page format, count, paper, opening range, binding method |
| Cover core | Bookbinding board with selected covering | Board thickness, joint geometry, cover overhang, decoration mass |
| Cover surface | Leather, faux leather, cloth, or coated texture | Final material, finish, wear appearance, flexibility |
| Metal-looking ornament | Thin actual metal or lightweight molded/printed decoration with finish | Mass, edges, fastening, board reinforcement |
| Fine tracery | Printed, embossed, engraved, or applied ornament | Technique, level of detail, minimum line size |
| Large medallion | Multi-part relief with separate center and rays | Projection, handling clearance, mounting, protection |
| Organic tendrils | Sculpted/molded/printed relief | Fragility, edges, attachment, handling clearance |
| Closures/chains | Actual fittings designed around the closed and opening book | Anchors, engagement, release, cover/page clearance |
| Ribbon/bookmark | Flexible strip compatible with the page block | Attachment, length, thickness, finish |
| Lighting | External scene light or narrowly integrated decorative lighting | Power, routing, heat, maintenance, joints, usable page space |
| Upright display | Separate support appropriate to the finished object | Center of mass, contact surfaces, pose |

The curled cover in book-06 is a reference appearance, not a ready functional cover design. Deep relief, long rays, overhanging tendrils, chains, and hardware need explicit handling and opening checks. Do not claim the entire photographed silhouette is workable as a bound book without those checks.

## Display prop with simulated pages

The conceptual assembly is a shaped shell, simulated page-block perimeter, cover/spine decoration, and optional interior cavity. Lighting access and upright support can be designed into this track.

| Assembly | Proposed options | Decisions before construction |
|---|---|---|
| Main shell | Board, wood, formed plastic-like shell, or printed parts | Target dimensions, rigidity, assembly, weight |
| Page edges | Layered material, sculpted striations, printed texture, or real edge stacks | Depth, edge irregularity, visible sides, finish |
| Spine | Static shaped shell with separate bands | Profile, rear seam, attachment, access |
| Ornament | Separate sculpted/molded/printed or fabricated pieces | Material, projection, attachment points, replacement |
| Lit center | Colored/translucent insert over a proposed diffused light | Cavity depth, hotspots, surface brightness, access |
| Lit lines | Translucent paths or light-guiding decorative elements | Minimum features, uniformity, attachment |
| Lit page edge | Diffused translucent simulated-edge feature | Preserve visible page texture; decide which edges illuminate |
| Internal access | Removable rear panel, lower panel, or proposed opening shell | Fasteners, concealed seams, service route |
| Power/wiring | Concealed system selected after effect requirements | Source, ratings, cable routing, switch, access, thermal checks |
| Support | Separate stand or concealed base/support | Pose, stability, visibility, cable path |

This track may be fixed closed. A hollow shell must not be described as an opening book unless joints, stops, and clearances are separately designed.

## Special-effect limits

Illuminated inserts and local light pools can be treated as physical lighting proposals. Halos, floating motes, detached wisps, and light streaks are scene or optical effects. Static translucent ornament, suspended details, projection, or photography can be considered as approximations; this draft does not promise an identical free-floating effect.

The lit candle in reference 02 is a scene observation. Whether a later display uses a simulated candle or another lighting arrangement is unresolved. No flame or electrical construction instructions are included here.

## Release boundary

Before a fabrication draft, resolve overall dimensions, construction track, opening behavior, materials, fabrication method, ornament projection, supports, lighting hardware, and access. Record a proposed BOM only after these choices exist. No current quantities of purchased material, fastener sizes, voltage, power, tolerances, or certified performance are specified.
